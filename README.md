# На кухне — заявки и закупки

Адаптивное веб-приложение для заявок кухни: су-шефы выбирают продукты, провизор видит список по поставщикам, шеф-повар управляет аккаунтами и справочниками. Стек: React + FastAPI + PostgreSQL.

## Быстрый запуск

Нужен Docker Desktop с Docker Compose.

1. Скопируйте `.env.example` в `.env`.
2. Для локальной проверки оставьте значения из примера.
3. Запустите из этой папки:

   ```sh
   docker compose up --build
   ```

4. Откройте [http://localhost:8080](http://localhost:8080).
5. Войдите как `admin` с паролем `ChangeMe123!` (если значения не менялись в `.env`). Создайте аккаунты су-шефов и провизора в разделе «Управление».

При первом запуске в базу загружается справочник из предоставленной книги: товары, категории и названия поставщиков. Активные заявки и тестовые количества из Excel не загружаются. У позиций с неподтверждённым поставщиком исходное название сохраняется для ручной проверки. Единицы товара остаются пустыми, так как книга не задаёт их для всего каталога; в списке закупки они отображаются как «ед.» до уточнения.

Остановка: `docker compose down`. Данные сохраняются в Docker volume `kitchen_db`. Чтобы полностью удалить данные локальной проверки вместе с базой: `docker compose down -v`.

## Серверный запуск

Перед публикацией измените в `.env` значения `POSTGRES_PASSWORD`, `SECRET_KEY` и `ADMIN_PASSWORD`, задайте домен для `CORS_ORIGINS`, включите `COOKIE_SECURE=true` и поставьте перед приложением HTTPS reverse proxy (например, Caddy, Traefik или Nginx). Не публикуйте порт PostgreSQL наружу. Секреты `.env` не добавляйте в Git.

Для запуска в фоне: `docker compose up --build -d`. Логи: `docker compose logs -f api web`. Резервная копия базы:

```sh
docker compose exec -T db pg_dump -U kitchen kitchen > kitchen-backup.sql
```

Восстановление в пустую базу:

```sh
docker compose exec -T db psql -U kitchen kitchen < kitchen-backup.sql
```

Если меняли `POSTGRES_USER` или `POSTGRES_DB`, подставьте их значения в команды резервного копирования.

## Роли

- **Шеф-повар:** все заявки, аккаунты и справочники; назначение поставщика товарам.
- **Су-шеф:** поиск по каталогу, категории, количества, комментарии, отправка и просмотр своих заявок.
- **Провизор:** заявки, группировка по поставщикам, статусы «К заказу», «Заказано», «Получено», «Нужно уточнить», выгрузка CSV.

Временный пароль сотрудника нужно сменить при первом входе. Шеф может отключить аккаунт или задать новый временный пароль.

## Компоненты

- `frontend/` — React интерфейс и Nginx для раздачи статики и проксирования API.
- `backend/` — FastAPI, модели данных, авторизация и REST API. Документация API доступна по `/docs`.
- `data/seed.json` — стартовый каталог, подготовленный из книги. Количества заявок из шаблонных листов сюда не включены.
- `docker-compose.yml` — приложение, API и PostgreSQL.
